书签小工具

把下面这个按钮拖到浏览器书签栏。以后在任何页面点一下， 它就把当前页地址送到拾链并自动开始分析——不用复制、切窗口、粘贴、回车。

1. 拖到书签栏

存到拾链 ↑ 按住这个按钮，拖到浏览器书签栏（Ctrl+Shift+B 可以显示书签栏）

2. 用起来

看到一个有意思的网站，点书签栏上的「存到拾链」。 会弹出一个窗口，AI 已经在分析了。挑一句备注、看一眼分类，点「就这样存」。

3. 前提

后端和前端都得在跑（本机自用，没部署到服务器）：

cd D:\workspace\shilian\server
./mvn.sh spring-boot:run

cd D:\workspace\shilian
npm run dev

后端没起的时候，拾链会直接告诉你「后端没连上」，不会静默失败。

它是怎么工作的

本质就是一个普通链接，指向 /?url= 加上当前页地址： 


    

      没有装扩展、没有后台服务、没有跨域请求。就是一次普通的页面跳转，
      所以它不会被浏览器的安全策略拦掉，也不需要任何权限。
    

  


  

    
如果拖拽不管用

    

      有些浏览器不允许拖拽 javascript: 开头的链接。
      那就手动新建一个书签，名称随便填，地址粘贴成上面那段代码即可。
